# 번호별 발행 큐

현재 번호는 active-plan.json의 2026-10-10 계획 1~8번입니다. 과거 계획은 archive 및 날짜별 파일로 보존합니다.

사용자가 '1번 배포해줘'라고 요청하면 해당 항목의 본문 2,000자 이상, 실제 이미지 3~5개, FAQ 5개, 출처와 내부 링크를 완성하고 중복·SEO·의료 표현 검수, 빌드, 해당 글만 커밋·push, 운영 배포 확인 순서로 처리합니다. 현재는 기획만 저장했고 초안과 이미지는 배포 요청 시 생성합니다.

pubDate는 실제 본문 작성일을 유지하고 updatedDate는 실제 배포일의 한국 날짜(Asia/Seoul)로 갱신합니다. publish:queued도 기존 작성일을 유지합니다. --date는 사용자가 날짜를 명시한 경우에만 사용합니다. 운영 페이지의 Last updated 및 dateModified 확인 후 발행 상태를 확정합니다.

추천 순서와 제목·메타 제목·slug·썸네일·검색 의도·중복 차별점·내부 링크는 active-plan.json에 저장되어 있습니다. 검색량 통계가 아닌 콘텐츠 공백에 따른 편집 우선순위입니다.
