# 번호별 발행 큐

현재 번호는 active-plan.json의 2026-10-24 계획 1~8번입니다. 이전 완료 계획은 archive/2026-10-10-seo-geo-nutrition-gaps.json에 보존했습니다.

사용자가 “1번 배포해줘”라고 요청하면 현재 계획의 1번 글을 작성·검수·빌드·배포합니다. 본문과 실제 이미지 생성은 배포 요청 시 진행합니다. 세부 실행 지침과 중복 방지 범위는 active-plan.json을 따릅니다.

pubDate는 실제 본문 작성일을 유지하고 updatedDate는 배포일의 한국 날짜(Asia/Seoul)로 설정합니다. 운영 페이지의 최종 업데이트와 dateModified 확인 후 발행 완료를 확정합니다. 현재 작업에서는 배포하지 않았습니다.
